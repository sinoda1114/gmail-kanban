# ユーザー目線の機能確認

自分が案件メールを追うときに、このアプリで何をするかの手順。開発者向けのテスト手順ではない。

## 今どこを開くか

`https://gmail-kanban.vercel.app` は今、古い Vite サイトを向いている。`/sign-in` は 404 になるので使わない。

機能確認は次のどちらか。

- 手元: `http://localhost:3000`（ホストは `localhost`。`127.0.0.1` だとログイン画面が壊れやすい）
- Vercel の Next.js デプロイ: [プロジェクト](https://vercel.com/sinoda1114s-projects/gmail-kanban) から最新 Production / Preview を Visit。Deployment Protection の SSO を通す。Google は押さず、メールで入る。

Free プランは案件 5 件まで。確認用の案件は最後に削除してよい。AI 生成（面談準備・振り返り・返信ドラフト）は Gemini を使う。

---

## 公開ページ

未ログインの入り口。カンバンは出さない。

1. ログアウトした状態で `/` を開く。
2. 見出し `Gmail Kanban`、ボタン `無料で始める` と `ログイン` があることを見る。
3. `無料で始める` がサインアップ、`ログイン` がサインインに進むことを押して確認する。

ログインしたまま `/` を開くと、ダッシュボードへ飛ぶ。

---

## アカウント

Clerk の画面でアカウントを作るか、既存アカウントで入る。

1. `/sign-up` でアカウントを作る。または `/sign-up` の `Sign up` から。
2. `/sign-in` でログインする。Google でもメールでもよい。
3. 未ログインのまま `/dashboard` を開くと、サインインへ戻される。

初回ログイン直後は `/onboarding` を一瞬通ってユーザー行が作られ、`/dashboard` に着く。特別な入力画面ではない。

---

## カンバン

ログイン後のホーム。今どの案件が、誰の番か、を見る場所。

1. ヘッダー左の `Gmail Kanban`（`ダッシュボードへ移動`）で `/dashboard` に戻れる。
2. 見出し `案件カンバン`、右上に `要対応` と `案件登録` がある。
3. 案件が無いときは「案件がまだありません。「案件登録」から追加してください。」と出る。
4. 案件があるときは列が出る。既定で見える列は `返信必要` / `相手返信待ち` / `書類選考中` / `面談調整中` / `面談予定` / `結果待ち`。`終了` と `保留` はスイッチ `終了・保留を表示` をオンにするまで隠れる。
5. 検索欄（プレースホルダ `タイトル・エージェント・技術・次アクションで検索`）に既知のタイトルを入れて、該当カードだけ残ることを見る。`クリア` で戻す。
6. カードのステータス変更、またはドラッグで列を移す。ダッシュボードを開き直しても同じ列にいること。

カードの `詳細` が案件ページ。面談日時が入っているカードだけ `面談準備` ショートカットが出る。

---

## 案件登録

Gmail の募集メールを、1 案件として置く。

1. カンバンの `案件登録`、または `/dashboard/projects/new`。
2. 見出し `案件登録`。`キャンセル` はリンクで、押すとカンバンに戻り案件は増えない。
3. **手入力（最小）:** `案件タイトル *` だけ入れて `登録する`。案件詳細（URL が `/dashboard/projects/…`）に進み、見出しが今付けたタイトルになる。`案件一覧へ戻る` でカンバンに同じタイトルがある。
4. **Gmail から（本丸）:** 設定で Gmail が連携済みなら、`Gmail URL / スレッド ID` を貼って `Gmailから取得`。本文欄にメールが入り、必要なら `AIで整理する`。`FMfcgz` で始まる新しい Gmail URL は取れない。そのときは本文を手で貼る。
5. 画面上の件数表示（例: `案件 4 / 5 件`）を見る。5 件に達すると `登録する` が押せなくなり、`プラン画面へ` が出る。

---

## 案件詳細（基本情報）

1 案件の中身。ステータス、次アクション、返信の下書き。

1. カードの `詳細`、またはカンバンから案件を開く。タブ `基本情報` が最初。
2. 鉛筆で編集して保存し、通知 `更新しました`。ページを開き直しても値が残る。
3. ステータスを変える（カード側でも可）。タブ `履歴` に変更の列が出る。
4. メール本文があるとき、`返信ドラフトを生成` を試せる。生成文は画面に出る。Gmail へ自動送信はしない。
5. 不要になった確認用案件は削除（確認ダイアログあり）。取り消せない。

---

## 面談準備

面談の前に、想定質問・逆質問・ブリーフを同じ案件に置く。

1. 案件詳細のタブ `面談準備`。見出し `面談情報`。
2. 日時・URL・形式などを入れて `保存`。カレンダー連携済みなら `カレンダーに追加` も使える。
3. `AIで面談準備を一括作成`（2 回目以降は `AIで面談準備を再生成（拡張含む）`）。想定質問などが出る。
4. 同じ案件に面談振り返りが保存済みだと、「この案件の面談振り返りを、準備の生成に反映します」と出る。中身の編集は面談メモタブ。

生成に失敗しても、直前の準備は残る。

---

## 面談メモと振り返り

面談中・直後のメモと、それを整理した振り返り。

1. 案件詳細のタブ `面談メモ`。
2. メモを書いて保存（通知 `面談メモを保存しました`）。
3. 空のまま `振り返りを生成` はできない。メモを入れてから押す。
4. 生成結果を見て、必要なら直して `振り返りを保存`。
5. もう一度 `面談準備` を開くと、振り返り反映の案内が出る。再生成すると次回の質問に乗るか見る。

---

## 要対応

「今自分が動くもの」だけを拾う。

1. ヘッダーまたはカンバンの `要対応`。見出し `要対応一覧`。
2. 何も無ければ「現在、対応が必要な案件はありません。」
3. 返信待ちが長い案件や、近い面談があると行が出る。種類は `要対応` / `催促候補` / `面談準備リマインド` / `進捗確認候補` / `再確認候補`。
4. `対応済み` を押すと、既定の一覧から消える。ページを開き直しても消えたまま。
5. 対応済みが 1 件以上あるとスイッチ `対応済みを表示` が出る。オンにするとバッジ `対応済み` 付きで戻る。

トーストだけ見て終わらず、開き直して残っているかを見る。

## 設定と Google 連携

カレンダー登録と Gmail 取得のための接続状態。トークンの中身は出ない。

1. ヘッダー右の `設定`。見出し `設定`。
2. `Google カレンダー連携` が `連携済み` か `未連携`。
3. `Gmail 連携` も同様。読み取り専用スコープ `https://www.googleapis.com/auth/gmail.readonly` の説明がある。
4. 未連携なら、右上のユーザーメニュー → アカウント管理から Google を足す。足したらこのページを再読み込みする。
5. 説明ページ `/dashboard/gmail`（リンク `Gmail 連携の説明`）は権限と URL 制限の案内。案件はここからは作らない。`案件登録へ` で登録画面に戻る。

連携済みバッジは「Clerk が Google トークンを持っている」ことまで。Calendar / Gmail の権限が足りないと、カレンダー追加や Gmail 取得でエラーになる。

## プラン

Free / Pro と件数上限。

1. ヘッダーの `プラン`。見出し `プラン`、`現在のプラン`、`アップグレード`。
2. バッジが `Free` か `Pro`。`案件数:` がカンバンの件数と合う。
3. Stripe 未設定の環境では「課金はまだ設定されていません。アップグレードは現在利用できません。」でよい。キーが載っていないこと。
4. 設定済みなら `Pro にアップグレード`。本番の課金確認以外では Checkout を完了しなくてよい。
5. 顧客がいるときだけ `お支払いを管理`（Customer Portal）。

Checkout 直後の `?success=true` は受付表示。Webhook 待ちでバッジがしばらく Free のまま、ということがある。

## 一通りの流れ（最短）

新規ユーザーが「使える」と思える最小セット。

1. ログアウトで LP を見る → `ログイン`。
2. ダッシュボードに着く。
3. 設定で Google が未連携なら、この時点で繋ぐ（Gmail 取得を試すなら）。
4. 案件登録。タイトルだけでも可。Gmail URL があれば取得も試す。
5. カンバンにカードがある。ステータスを 1 つ変える。
6. 詳細で返信ドラフトを 1 回（本文があるとき）。
7. 面談準備を 1 回生成する（使うなら）。
8. 要対応を開く。
9. プランの件数を見る。
10. 確認用案件を削除する。
